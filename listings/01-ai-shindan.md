## サービスの詳細

```
■ こんな状態ではありませんか

・AIを業務に入れたいが、どこから手を付ければいいか分からない
・ChatGPTやClaudeを触ってはいるが、業務の効率化には繋がっていない
・「AIで自動化できます」と言われたが、本当に効果が出るのか判断できない
・ツールが多すぎて、自分の業務にどれが合うのか選べない

このサービスは、あなたの業務を実際に調べて「何を、どの順番で、どの道具でやるか」を
1冊の診断書にまとめてお渡しします。


■ このサービスの一番の特徴：「やらない方がいいこと」も書きます

AI活用の相談は、たいてい「AIで解決できます」という結論になります。
しかし実務では、AIを使わない方が確実で安く済む領域が確かに存在します。

私は自分のプロダクト開発で、この判断を実際にしています。
飲食店向けのシフト作成システムを作った際、シフトの自動生成にAI（大規模言語モデル）を
使わないという結論を出しました。シフト作成は労働基準法という「絶対に破ってはいけない条件」を
含む問題で、AIはこの種の条件を必ず守ることを保証できないためです。
実装では数理最適化のアルゴリズムを自作し、AIの役割は「日本語で書かれた希望条件を
ルールに変換する入力部分」だけに限定しました。

診断書には、こうした判断の理由まで書きます。
「やらない方がいい」と言える相手でなければ、「やった方がいい」も信用できないと考えています。


■ 納品物：診断書（PDF・A4で10ページ前後）

1. 業務フローの棚卸し
   現状の作業の流れを1枚の図に整理します

2. AI・自動化で置き換えられる工程の特定
   どの作業が、どの程度の時間削減になるかを試算します

3. やる順番の3分類
   ・今すぐ着手すべきもの（1つに絞ります）
   ・3ヶ月後に着手するもの
   ・手を出さない方がいいもの（理由つき）

4. 道具の選定と、その理由
   Claude Code / n8n / GitHub Actions / スプレッドシート の使い分けを、
   あなたの業務に当てはめて示します

5. 概算ランニングコスト
   月額でいくらかかるか。無料でできる範囲も明記します


■ 進め方（お届け目安5日）

1日目　ご購入後、ヒアリングシート（Googleフォーム）をお送りします
　　　　業務内容・繰り返している作業・お使いのツール・月あたりの作業時間をご記入ください
2日目　必要に応じて30分のオンライン（ovice）で補足をうかがいます ※任意です
3〜5日目　診断書を作成し、納品します
納品後7日間　内容についてのご質問にDMでお答えします


■ なぜこの診断ができるのか

私は本業がITエンジニア（Java・Web、実務3年）で、個人事業として
Webサービスの開発と業務自動化を行っています。

【自分の業務で実際にやっていること】
・自社で10本以上のWebサービスを開発し、運用しています
　（給付金の計算ツール、沖縄の補助金検索サイト、シフト作成システムなど）
・業務自動化ツール（n8n）の運用費を、月4〜5ドルから0円に下げました
　クラウドの有料プランを解約し、手元のPC上で動かす構成に移し替えています
・毎日自動で情報を収集し、変更があった箇所だけをAIに判定させる仕組みを運用しています

【お客様の業務でやったこと】
・建設業のお客様向けに、日報と経理を1つにしたWebアプリを開発
　実作業10人日で納品しました（一般的な見積もりでは90〜100人日規模の内容です）
・一般企業向けに勤怠管理アプリを開発
　実作業5人日で納品しました（同じく45〜50人日規模の内容です）

この「実際に自分の手を動かした量」が、診断の精度の根拠です。
AIツールの紹介記事を読んだだけでは、どこで詰まるかが分かりません。


■ こんな方に向いています

・個人事業主、または従業員10名以下の事業者の方
・繰り返しの事務作業に時間を取られている方
・AIの導入を検討しているが、投資判断の材料が欲しい方
・すでにツールを入れたが、使いこなせていない方

■ こんな方には向いていません

・すでにAI活用の方針が固まっていて、実装だけを依頼したい方
　→ 実装のご相談は別サービスで承ります
・その場ですぐに回答が欲しい方
　→ このサービスは調査して書面にする形式のため、お時間をいただきます


■ 料金とお支払い

■ ご注意ください

・診断書は「何をすべきか」を示すものです。ツールの実装作業は含みません
・無料修正1回は、診断書の記述の訂正・補足に対応するものです
　ヒアリング時にお伝えいただいていなかった業務が後から判明した場合は、
　前提が変わるため再診断となり、別料金となります
・診断の結果、「現時点ではAIを導入しない方がよい」という結論になる場合があります
　その場合も診断書は納品し、返金はいたしかねます（その判断自体が診断の成果物です）
```

## サービスの詳細

```
■ こんなことに使えます

・補助金や助成金の公募ページ（受付開始・締切・金額の変更を逃さない）
・競合他社の価格ページ、サービス内容のページ
・仕入れ先の在庫や取扱商品のページ
・自治体や官公庁のお知らせページ
・自分が申し込んでいる制度の、条件変更のお知らせ

「たまに見に行かないといけない」と分かっているのに、忙しいと飛んでしまうページを、
毎日きっかり見に行く係を作ります。


■ このサービスで一番大事にしていること：通知が邪魔にならないこと

ページの差分をそのまま送る仕組みは、実は簡単に作れます。
ただ、それだと毎日「変わりました」が飛んできます。
広告の差し替え、日付表示、アクセスカウンタ。中身が変わっていなくても差分は出るからです。
そして人は、毎日届く通知を1週間で読まなくなります。

そこで、判定を二段構えにします。

1段目　ページの中身をハッシュ（指紋のようなもの）で比べ、変化した候補だけを拾う
2段目　その変化が「実質的な変更か」をAI（Claude）に判定させる

締切日が変わった、金額が変わった、受付が始まった。
そういう「あなたが知りたかった変化」のときだけ通知が飛びます。


■ PDFにも対応します

補助金や入札の情報は、肝心の金額や条件が募集要項のPDFにしか書かれていないことがよくあります。
PDFの中身をテキストとして取り出したうえで比較します。


■ 暴走しないための安全装置を入れます

自動監視でいちばん困るのは、誤検知が連鎖して通知が大量に飛ぶことです。
次の2つを最初から入れます。

・巡回した件数のうち30%を超えて変更が出たときは、サイト全体の改修とみなして
　その回の結果をすべて破棄します（1件ずつ通知が飛び続ける事態を防ぎます）
・ページが見つからない（404）ときは、3日連続で確認できたときだけ「終了した」と判断します
　（一時的な障害で「終了しました」と誤報しないため）


■ 私が実際に運用しているもの

沖縄県41市町村の補助金・給付金を集めたサイトを運営しており、
その掲載元である公式ページを毎日1回（深夜3時）巡回して、
変更を検出したら内容を自動で更新する仕組みを動かしています。
対象は400件を超える公式ページです。

https://uchina-money.nexeed-lab.com

上記のサイトでは「最後に人が確認した日からの経過日数」を公開しており、
仕組みが実際に回っていることをサイト上で確認できます。


■ 納品するもの

1. 監視の仕組み一式（クラウド上で動きます）
2. 通知の設定（LINE / Slack / メール のいずれか）
3. 監視するページを、あとからご自身で追加・削除するための手順書
4. 「どう判定させたいか」の設定ファイル
　　（例：締切と金額だけ見てほしい／文言の変更は無視してほしい）

監視対象は5ページまでを標準とします。
それ以上は1ページあたり1,000円で追加できます（ご購入後にご相談ください）。


■ 実行環境とランニングコスト

GitHub Actions（クラウド）で動かします。あなたのパソコンは関係ありません。
標準的な構成（5ページ・1日1回）であれば、無料の範囲で収まる見込みです。
無料枠を超える構成が必要な場合は、着手前に月額の目安をお伝えします。


■ 進め方（お届け目安14日）

1〜3日目　監視したいページと、知りたい変化の種類をうかがいます
4〜10日目　実装し、実際に数日走らせて誤検知が出ないかを確認します
11〜13日目　通知先の設定と、動作のご確認をしていただきます
14日目　手順書をお渡しして納品です
納品後14日間　通知の調整についてのご相談にDMでお答えします


■ 正直にお伝えしておくこと

・通知は1日1回が基本です。「変わった瞬間に知りたい」用途には向きません
・ログインが必要な会員ページは対象外です（公開されているページのみ）
・ページの作りが特殊な場合（画像だけのページ、JavaScriptで後から中身を差し込むページなど）は、
　取得できないことがあります。ご依頼時にURLを確認させてください
・利用規約で自動アクセスを禁止しているサイトは、お受けできません
・変更の「見落とし」をゼロにする保証はできません。仕組みは補助であり、
　重要な締切はご自身でも確認いただく前提でお使いください


■ こんな方に向いています

・補助金や助成金を継続的に取りに行きたい事業者の方
・競合や仕入先の情報を定期的に見ている方
・「見に行くのを忘れて損をした」経験がある方

■ こんな方には向いていません

・秒単位・分単位の即時通知が必要な方（在庫の争奪など）
・ログインの内側にある情報を見たい方


■ 料金とお支払い

10,000円（監視対象5ページまで・通知先1つ）
お支払いはリベポイント、または銀行振込に対応しています。


■ 対応可能時間

平日　20:00〜23:00
土日祝　9:00〜12:00 / 13:00〜17:00 / 20:00〜23:00
DMへのご返信は24時間以内に行います。


■ 秘密の保持について

監視対象・通知内容・ご相談の内容は、この開発以外の目的には使用せず、第三者に開示しません。


■ 参考：私が開発・運用しているサービス

・沖縄県41市町村の補助金・給付金の検索サイト（本サービスと同じ仕組みで更新しています）
```

## キャンセル時の注意事項

```
■ キャンセルが可能なタイミング

監視対象のURLを確認する前まではキャンセルを承ります。全額返金いたします。

URLを確認し、取得可否の判定に着手した時点からキャンセル不可とさせていただきます。

■ 着手前に監視できないと判明した場合

ご指定のページが次のいずれかに該当する場合は開発に着手せず、全額返金いたします。

・ログインが必要で、公開ページとして取得できない場合
・サイトの利用規約が自動アクセスを禁止している場合
・ページの構造上、安定して中身を取得できないと判断した場合

判断の理由は文章でお伝えします。

■ 納品後について

納品後の返金は原則としてお受けしておりません。

無料修正1回は、通知の条件（何を変更とみなすか）の調整に対応するものです。
監視対象ページの追加や、対象サイトの全面改修に伴う作り直しは、前提が変わるため
別途のご依頼となります。

■ 検出の精度について

この仕組みは変更の見落としをゼロにするものではありません。
サイト側の障害、構造の変更、判定の誤りにより、通知されない変更が生じる可能性があります。
これに起因して生じた損害（申請期限の徒過など）について、責任を負いかねます。
重要な締切はご自身でも確認いただく前提でご利用ください。
```
